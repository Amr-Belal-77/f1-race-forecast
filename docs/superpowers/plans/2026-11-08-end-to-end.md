# F1 End-to-End Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. The user delegated scope and execution; proceed inline.

**Goal:** Deliver a reproducible ML pipeline, interactive dashboard and verified GitHub repository.

**Architecture:** Add a package beside the original scripts. Share feature logic between backtesting and inference; keep generated artifacts separate. Commit small demonstration reports for dashboard startup without training.

**Tech Stack:** Python >=3.11, pandas, scikit-learn, XGBoost, Streamlit, pytest, Ruff, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-08-end-to-end-design.md`

## Global Constraints

- Preserve original scripts and artifacts.
- Cutoff strictly before 2026-11-08; 2026 diagnostics separate.
- No calibrated-probability or independently verified-input claims.
- No environments, caches, credentials or model binaries in Git.

## Review Focus

- Missing/new drivers use imputation without borrowing future performance.
- Invalid or duplicate grids, labels, race keys and dates fail before training.
- Current race outcomes cannot affect current features; target and history formulas agree.
- Empty evaluation folds and scores that cannot normalize fail explicitly.
- Fresh-checkout dashboard works; custom output directory is supported.
